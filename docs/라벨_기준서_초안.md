# 운동화 손상 라벨 기준서 (연습용 초안 v0.1)

> 여러 작업자가 같은 기준으로 라벨링하도록 만든 초안입니다.
> 교차 검수 결과에 따라 예시와 경계 사례를 계속 추가합니다.

## 1. 클래스

| id | 이름 (COCO category) | 한글 | 표시 대상 |
|---|---|---|---|
| 0 | `heel_lining_damage` | 뒤꿈치 안감 손상 | 신발 안쪽 뒤꿈치 안감이 해지거나 찢어져 아래 층(스펀지, 보강재)이 보이는 부분 |
| 1 | `sole_separation` | 밑창 들뜸 | 갑피(윗부분)와 밑창 사이가 벌어져 틈이 보이는 부분 |

클래스 이름은 위 표기만 씁니다. `Sole Separation`, `sole-separation`, `밑창들뜸` 같은 변형은 audit 도구가 잡아냅니다.

## 2. 표시 방법

- **다각형(polygon)** 으로 손상 영역을 그립니다. 박스는 다각형에서 자동 계산합니다.
- 손상 하나 = 다각형 하나. 떨어져 있는 손상 두 곳은 다각형 두 개.
- 다각형은 손상 가장자리에서 **2~3px 바깥**까지 포함합니다. 너무 딱 맞추면 작업자마다 차이가 커집니다.

### 뒤꿈치 안감 손상 (`heel_lining_damage`)
- 포함: 안감이 해져 **아래 층이 보이는** 영역 전체, 찢어진 안감 조각이 걸려 있으면 그 조각까지
- 제외: 단순 보풀, 변색, 얼룩, 눌린 자국(아래 층이 안 보이면 손상 아님)
- 애매: 얇아져 비치기만 하는 부분 → `review` 태그 달고 표시하지 않음

### 밑창 들뜸 (`sole_separation`)
- 포함: 갑피와 밑창 사이에 **눈으로 보이는 틈**이 있는 구간. 틈의 길이 방향으로 길게 그림
- 제외: 원래 디자인상 홈, 접착제가 삐져나온 자국, 흙 낀 이음새
- 애매: 틈인지 그림자인지 구분 안 됨 → `review` 태그

## 3. 사진 단위 판단

| 상황 | 처리 |
|---|---|
| 손상 없음이 확실 | 라벨 없이 둠 (정상 사진, 학습에 포함) |
| 손상 있는데 가려서 일부만 보임 | 보이는 부분만 그림 |
| 흐림, 너무 어두움 | 이미지 태그 `bad_image`, 학습 제외 |
| 기준으로 판단 불가 | 이미지 태그 `review`, 2차 검수자가 결정 |

## 4. 자동 초안(GPT·SAM 등) 처리 원칙

- 자동 초안은 **정답이 아니라 출발점**입니다. 사람이 모든 다각형을 확인해야 `verified` 상태가 됩니다.
- 사람이 고친 결과와 자동 초안은 별도 버전으로 보관합니다(덮어쓰지 않음).
- 평가(test) 데이터에는 `verified` 라벨만 씁니다.

## 5. 교차 검수

- 같은 사진 20장을 두 사람이 각각 라벨링 → 다각형 IoU와 클래스 일치율 비교
- IoU 0.5 미만이거나 클래스가 다른 사진은 함께 보고 기준서에 예시 사진을 추가

## 6. 열린 질문 (팀과 합의할 것)

- 안감 손상과 **뒤꿈치 외피 마모**를 구분하는지
- 밑창 들뜸이 **앞코 쪽**에 있을 때도 같은 클래스인지
- 한 사진에 신발 두 짝이 나오면 둘 다 라벨링하는지
