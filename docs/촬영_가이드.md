# 연습용 데이터 촬영 가이드

집에 있는 운동화로 작은 데이터셋을 직접 만듭니다.
**같은 신발, 같은 세션을 기록**하는 것이 핵심입니다. 그래야 같은 신발이 학습과 평가에 섞이는 누수를 막을 수 있습니다.

## 목표 규모

- 신발 10~15켤레(가족, 친구 것 포함), 손상 있는 신발이 절반 이상이면 좋음
- 신발 한 짝당 4장 × 촬영 세션 2번 → 약 150~250장

## 파일 이름 규칙 (도구가 이 이름으로 신발을 묶습니다)

```
S{신발번호 3자리}_{세션}_{부위}_{번호 2자리}.jpg
예: S001_A_heel_01.jpg, S001_B_soleL_02.jpg
```

| 항목 | 값 |
|---|---|
| 신발번호 | 켤레마다 하나 (S001, S002, ...). 왼쪽·오른쪽 짝은 같은 번호 |
| 세션 | A = 낮 창가, B = 밤 형광등 (조명이 다른 날) |
| 부위 | `heel` 뒤꿈치 안쪽, `soleL` 밑창 왼쪽 측면, `soleR` 오른쪽 측면, `top` 위에서 |

같은 신발 사진은 학습·검증·시험 중 **한 곳에만** 들어가야 합니다. 이름 규칙을 지켜야 `split.py`가 자동으로 묶어 줍니다.

## 촬영 요령

- 휴대폰 기본 카메라, 신발과 20~40cm 거리
- 매장 접수 사진처럼 **배경은 일부러 통일하지 않아도 됨** (실제 데이터의 편차를 흉내)
- 세션 A와 B는 다른 날, 다른 조명으로
- 흔들린 사진도 지우지 말고 둡니다. audit와 라벨링에서 `bad_image`로 걸러내는 연습용

## 라벨링 (CVAT)

1. [app.cvat.ai](https://app.cvat.ai) 무료 계정 생성 (직접 가입)
2. Project 만들기 → Label 2개: `heel_lining_damage`, `sole_separation` (Polygon)
3. Task에 사진 업로드 → 기준서대로 다각형 그리기
4. Export: **COCO 1.0** 형식 → `annotations.json`과 `images/` 폴더로 정리
